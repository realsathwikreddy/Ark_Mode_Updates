# Ark Mode updates

Public files the Ark Mode app downloads by itself:

- `version.json`: the latest version numbers
- `bundles/`: over-the-air updates for the app's screens and code
- `ArkMode.apk`: the latest full app, for updates that change the native Android parts
- `feed.json`: the Radar opportunities feed, refreshed every 6 hours by `scripts/feed.mjs`
